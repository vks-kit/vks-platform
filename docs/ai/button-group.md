# Button group

> Joined buttons for a small set of related actions or views.

- Group: Actions · New
- Source: `packages/ui/src/components/desktop-kit.tsx`
- Live docs: #/docs/button-group

```ts
import { ButtonGroup } from "@vks/ui"
```

## When to use

- **ButtonGroup**: Joins Buttons into one segmented bar (shared borders, rounded ends). For single-choice toggles use ToggleGroup instead.
